制造业 ERP-MES 集成生产管理平台

面向离散制造企业的数字化生产管理系统

项目简介

本系统基于 RuoYi 开源框架进行二次开发， 实现制造企业从订单管理、生产计划、 生产执行到库存管理的一体化业务流程。

核心功能

  • 基础数据管理：产品、物料等生产基础信息维护
  • 订单与生产计划管理：支持制造任务下达
  • MES生产执行： 生产任务创建、开始生产、完工确认
  • 库存管理： 生产完工自动生成入库记录并更新库存数量

技术架构

  • Spring Boot + Spring MVC
  • MyBatis持久层框架
  • MySQL数据库
  • Thymeleaf + Bootstrap前端页面
  • 基于RuoYi权限管理框架二次开发
